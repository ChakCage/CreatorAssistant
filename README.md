# Creator Assistant

Windows desktop application for preparing public YouTube video materials for editing and voice-over workflows.

The public **Creator Assistant Developer Preview** is a standalone Windows edition for testing and development. It requires no subscription, activation code, Creator Assistant backend, Telegram bot, or payment service.

[Полная документация на русском языке](README_RU.md)

The Project Preparation module supports metadata discovery, maximum SDR video, configurable 480p/720p/1080p REAPER proxies, original audio, previews, Instrumental FLAC, manifests, resume, progress, cancellation, disk-space checks, and REAPER project creation.

Developer Preview includes Project Preparation, Shorts and the vertical editor, local Ollama/Whisper AI, Autopilot, publishing tools and diagnostics. Its first-run wizard checks local dependencies and installs supported open-source components only after explicit confirmation.

The separate Commercial edition remains the future subscription product. Developer Preview never uses the Commercial activation or update channel.

User settings, cookies, media, logs, external runtimes, and models are not stored in this repository.
