# Creator Assistant Commercial Staging — руководство закрытой беты

## 1. Установка

1. Скачайте `CreatorAssistant-Commercial-Staging-Setup-<версия>.exe`.
2. Сверьте SHA-256 с `SHA256SUMS.txt`.
3. Запустите установщик. Права администратора не требуются.
4. Пока сборка не подписана коммерческим Authenticode-сертификатом, Windows SmartScreen может показать предупреждение. Проверяйте имя файла и SHA-256.
5. Staging устанавливается отдельно от обычной Commercial и Developer.

## 2. Первый запуск

Мастер последовательно предлагает активировать тестовую лицензию, проверить компьютер, настроить Ollama, выбрать `qwen3:14b` или `qwen3.6:35b-a3b`, проверить Whisper/FFmpeg и выбрать рабочие папки. AI можно настроить до активации, но лицензионные операции начнутся только после успешной активации.

## 3. Ollama

Ollama должна отвечать только на `http://127.0.0.1:11434`. Модели не входят в установщик Creator Assistant и не удаляются при обновлении/удалении программы. Если на C мало места, задайте пользовательскую переменную `OLLAMA_MODELS` на каталог другого диска до загрузки модели.

## 4. Первый проект

1. Во вкладке «Подготовка проекта» выберите автора и вставьте ссылку YouTube.
2. Проверьте найденные пути yt-dlp, FFmpeg, FFprobe, VEGAS/REAPER.
3. Запустите подготовку и дождитесь MAX/proxy/audio.
4. Перейдите в Shorts, выберите исходник и запустите анализ.
5. Проверьте кандидатов, субтитры, вертикальную композицию, заголовок и баннер.
6. Выполните тестовый 5-секундный рендер, затем пакетный рендер.
7. Готовые MP4 находятся в `Shorts\Renders`.

## 5. Обновление и сохранность данных

Обновление заменяет только файлы в `%LOCALAPPDATA%\Programs\CreatorAssistant\Commercial-Staging`. Проекты, рендеры, AppData, лицензия, бренд-материалы и общие модели находятся вне каталога установки и сохраняются.

## 6. Отчёт об ошибке

Откройте «Диагностика» → «Создать пакет для поддержки». Перед сохранением программа покажет состав ZIP. Пакет не отправляется автоматически и не содержит видео, transcript, OAuth/cookies, лицензионные токены, private keys или платёжные секреты.
