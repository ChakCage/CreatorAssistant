# Creator Assistant — Shorts MVP

Shorts — независимый локальный модуль в ветке `feature/shorts-mvp`. Стабильная вкладка «Подготовка проекта» остаётся без изменения публичного workflow.

## Рабочий процесс

1. Во вкладке «Shorts» выберите готовый локальный ролик либо папку проекта Creator Assistant.
2. Выберите папку для нового проекта Shorts. Исходник проверяется через FFprobe и никогда не изменяется.
3. Настройте длительность и число кандидатов, затем запустите анализ.
4. Приложение создаёт H.264 720p analysis proxy, mono PCM 16 kHz, локальную расшифровку Whisper, сцены и сведения об активности звука.
5. Проверьте реальные кандидаты, измените границы, одобрите или отклоните их.
6. Выберите Center Crop либо Blur Background, исправьте отдельную копию субтитров и сохраните SRT/ASS.
7. Добавьте одобренные фрагменты в последовательную очередь рендера. Итог создаётся из оригинального файла в MP4 1080×1920 H.264/AAC.

## Локальный Whisper

Автоматический режим сначала использует найденный headless `openai-whisper`. На проверенном компьютере это версия 20250625, Python 3.9.9, модель `large-v3-turbo` и CUDA/FP16 на RTX 5080. ML-пакеты не устанавливаются в `.venv` Creator Assistant или системный Python. Для будущей изолированной установки зарезервированы:

- `%LOCALAPPDATA%\CreatorAssistant\runtimes\whisper`;
- `%LOCALAPPDATA%\CreatorAssistant\models\whisper`.

Настройки backend, модели, языка, устройства, профиля, FP16, word timestamps и пользовательского словаря находятся в разделе «Распознавание речи».

## Кандидаты

Границы привязываются к фразам, паузам и сценам. Дефолты: 25–60 секунд, желаемая длина 45 секунд, 15 результатов. Эвристический scorer не заявляет человеческого понимания смысла и использует веса: hook 25%, самодостаточность 20%, развязка 15%, эмоция 15%, визуальная динамика 10%, темп речи 10%, уникальность 5%. Dedupe сравнивает перекрытие времени, похожесть текста и совпадение границ; отброшенные варианты сохраняются как альтернативные границы.

## Cache и resume

В `shorts_manifest.json` атомарно сохраняются fingerprint исходника, настройки этапов, кандидаты, решения и render jobs. Неизменённые proxy, WAV, transcript, сцены, audio features и кандидаты повторно не вычисляются. Изменение стиля субтитров или вертикальной компоновки не запускает Whisper.

## Вертикальный рендер

Filter graph строится сервисом, а не UI: `trim/setpts`, Center Crop либо Blur Background, `subtitles` (ASS/libass), `atrim/asetpts`. Для HDR добавляется локальный tone mapping в BT.709. Сначала используется проверенный `h264_nvenc`, при ошибке — `libx264`. После рендера FFprobe обязан подтвердить 1080×1920, H.264, AAC и ожидаемую длительность.

## Ограничения MVP

- нет автоматической публикации, YouTube/TikTok API и расписания;
- нет face tracking, split-screen, генерации мемов, музыки и обложек;
- эвристический ranking требует ручной проверки;
- QtMultimedia зависит от системных кодеков, поэтому доступно открытие proxy во внешнем проигрывателе;
- локальный Whisper может использовать более медленный DTW fallback без установленного CUDA Toolkit, хотя CUDA inference работает;
- пользователь отвечает за права на обрабатываемый контент.
