# Безопасное обновление Creator Assistant

Каждая редакция использует собственный канал:

- Developer — `developer`;
- Commercial — `stable`;
- Commercial Staging — `beta`.

Клиент принимает только manifest своей редакции, канала и архитектуры. Manifest подписывается отдельным Ed25519 update key; лицензионный ключ для этого не используется. Перед запуском установщика проверяются HTTPS, подпись, версия, SHA-256 и размер. Downgrade по умолчанию запрещён.

Обновление нельзя начать во время рендера, Whisper, Ollama-анализа, скачивания, UVR или миграции. При сбое скачивания старая версия остаётся рабочей. Проекты, лицензия, настройки, модели и бренд-материалы расположены вне install directory.
