# Быстрый старт закрытой беты

1. Скачайте `CreatorAssistant-Commercial-Staging-Setup-<версия>.exe`.
2. Сверьте SHA-256 из `SHA256SUMS.txt`.
3. Установите Commercial Staging; при SmartScreen проверьте издателя/хеш.
4. Получите тестовый код у разработчика и активируйте лицензию.
5. В мастере выберите AI-модель и при необходимости загрузите её через Ollama.
6. Создайте проект, найдите Shorts, проверьте вертикальный редактор и запустите пакетный рендер.
7. Готовые MP4 лежат в папке проекта `Shorts\Renders`.
8. При ошибке: «Диагностика» → «Создать пакет для поддержки» и приложите ZIP к отзыву.
