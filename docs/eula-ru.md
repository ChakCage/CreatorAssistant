# Пользовательское соглашение закрытой беты

Сборка предоставляется для ограниченного тестирования «как есть». Пользователь обязан иметь права на обрабатываемые материалы и соблюдать правила YouTube и других платформ. Запрещено передавать тестовый activation code третьим лицам или пытаться обходить технические ограничения лицензии.

Перед работой с важным проектом рекомендуется иметь резервную копию. Удаление программы по умолчанию сохраняет пользовательские данные; полное удаление выполняется только после отдельного подтверждения.
