# Creator Assistant Developer Preview 0.7.0

Это бесплатная standalone-редакция для тестирования и разработки. Подписка, код активации, Telegram-бот и сервер Creator Assistant не требуются.

## Быстрый старт

1. Установите приложение и запустите **Creator Assistant Developer Preview**.
2. Пройдите мастер компонентов. Он ничего крупного не скачивает без подтверждения.
3. При отсутствии FFmpeg/FFprobe и yt-dlp нажмите автоматическую установку.
4. Для AI установите официальный Ollama и модель `qwen3.6:35b-a3b` (примерно 24 ГБ) либо выберите «Пропустить пока».
5. Откройте «Подготовка проекта» или Shorts.

Мастер можно повторно открыть через **Настройки → Мастер первоначальной настройки**. Полная проверка находится в **Настройки → Компоненты / диагностика**.

## Внешние программы

REAPER, VEGAS Pro и DaVinci Resolve являются отдельными продуктами. Creator Assistant только обнаруживает их или позволяет указать путь. Приложение не устанавливает их автоматически и не обходит лицензирование.

## Локальная обработка и сеть

Проекты, видео, транскрипции и AI-анализ остаются на компьютере. Интернет объективно нужен для скачивания компонентов, моделей и материалов YouTube, а также для функций публикации. Недоступность серверов Creator Assistant не блокирует приложение.

## Windows SmartScreen

Developer Preview пока не подписана сертификатом Authenticode. Windows SmartScreen может показать предупреждение. Сверяйте SHA-256 установщика с файлом `SHA256SUMS.txt` в GitHub Release.
