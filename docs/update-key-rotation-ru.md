# Ротация update signing keys

Update keys полностью отделены от license signing keys.

1. Сгенерировать Ed25519 пару скриптом `scripts/generate-update-key.py` вне репозитория.
2. Private key хранить offline/в CI secret store; в EXE он никогда не включается.
3. Добавить новый public key и `key_id` в build metadata следующей версии.
4. В переходный период новая версия может доверять старому и новому public key только в своём канале.
5. После достаточного обновления клиентов перестать подписывать старым ключом и удалить его из последующих сборок.
6. Staging, stable и developer используют независимые пары.

При компрометации ключа release деактивируется, ключ отзывается в новой доверенной сборке, а пользователи уведомляются через проверенный канал.
